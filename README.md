# Personal Portfolio Website

A simple, modern, and dark-themed personal portfolio website to showcase my coding skills, school education, and coding projects to future employers. 

## Features
* **Single-Page Design:** All information is on one page for easy reading.
* **Smooth Scrolling:** Clicking the menu links smoothly glides the screen down to the right section.
* **Mobile-Friendly:** The layout automatically changes to look good on phone screens, tablets, and desktop monitors.
* **Neon Dark Theme:** A clean, dark background with bright cyan and purple colors.

## What It's Built With
* **HTML5:** For the main structure and text of the website.
* **CSS3:** For all the colors, spacing, grid layouts, and animations.
* **JavaScript:** A small script to make the sections fade into view when you scroll down.

## Sections Included
* **Hero/Intro:** My name and a quick summary of who I am.
* **About:** A short background about my studies and goals.
* **Skills:** A list of the programming languages and tools I know.
* **Projects:** Cards showing off the things I have built, with links to the code.
* **Education:** My school, degree, and expected graduation year.
* **Contact:** Links to my email, GitHub, and professional profiles.
